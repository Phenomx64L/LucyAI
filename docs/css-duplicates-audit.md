## Closed out

The v1.4.20 → v1.5.8 CSS dedup sprint is **closed**. Of the
original 232 duplicates, **231 have been resolved**: either
extracted to a dedicated stylesheet (167 selectors across 10
files) or reclassified as intentional shared utilities (9
selectors). The single remaining selector is a one-line
`.empty-ico` in `PdfIngestPanel.svelte` that survives only
because moving it would require also extracting the surrounding
PDF-ingest empty state — punted to whenever that surface gets
a deliberate pass.
