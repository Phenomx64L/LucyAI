## Critical knowledge (read this before touching shell.rs)

### `(sin salida)` will return if you forget any of these

```rust
Command::new("powershell")
    .args(...)
    .stdin(Stdio::null())      // close stdin: script is self-contained
    .stdout(Stdio::piped())    // ← THIS LINE specifically. Lose it and we lose all output.
    .stderr(Stdio::piped())    // capture stderr too — used by ReAct
    .spawn()
```

The contract test `powershell_captures_simple_stdout` catches this in
~2 seconds. Don't skip it.

### Why `execute_cmd` looks like it could lose them too but doesn't

`execute_cmd` uses `.output()` (the higher-level API) which configures
piped stdio implicitly. That's why CMD worked the whole time the
PowerShell capture was broken — and that asymmetry was the smoking gun
v1-v3 missed.

### Tokio macros

`tokio = { features = ["...", "macros"] }` — required for `#[tokio::test]`.
Don't drop it.

### Anti-hallucination guard

`+page.svelte` line ~4544 and ~4654 — the post-exec `ask_lucy` analysis
prompts have explicit MUST-NOT clauses. The earlier version said:

> "If no output, confirm the command ran successfully."

That string was actively training Gemini Flash to confabulate. The
replacement is verbose because it has to overcome the model's prior:

> "If the output is empty or shows `(sin salida)`, you MUST report that
> NO DATA was returned. DO NOT invent results, DO NOT claim 'executed
> successfully — no items found', DO NOT assume the command worked
> silently."

If you ever simplify these prompts: re-run the case-study from
`docs/screenshots/<dates>` to confirm Gemini still doesn't hallucinate.

## Files to copy when moving Claude Code session

Three layers, in order of importance:

1. **`%USERPROFILE%\.claude\projects\X--Rust-Projects-lucy-svelte\memory\`**
   — The auto-memory MDs. ~few KB. ALWAYS take these. They're how a fresh
   Claude session "remembers" project conventions, user prefs, prior
   decisions.

2. **`%USERPROFILE%\.claude\projects\X--Rust-Projects-lucy-svelte\<session-id>.jsonl`**
   — The literal conversation. Anywhere from 1 MB to 100+ MB depending on
   how long the session ran. Lets Claude Code `--resume` exactly where you
   left off.

3. **`%USERPROFILE%\.claude\projects\X--Rust-Projects-lucy-svelte--claude-worktrees-*\`**
   — If you ran any worktree-isolated sub-agents (Plan, Explore, etc.),
   their sessions live here. Probably skip unless you specifically want
   to replay one.

The repo itself (source code, history, hooks) is on GitHub — `git clone`
gets you 100 % of the actual product.
